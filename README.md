# Cinex

**Autores:** Renato Kriger e Gabriel Roberto

**Tema Escolhido:** Plataforma de Streaming de Vídeo (Filmes e Séries).

## Apresentação do Tema
A **Cinex** é muito mais do que um simples catálogo de filmes; é a nova dimensão do entretenimento em casa. O projeto consiste em uma plataforma de streaming moderna, intuitiva e focada na experiência do usuário. Nosso site oferece um acervo categorizado de filmes, séries e documentários premium, organizados para que o usuário encontre rapidamente o que deseja assistir. 

Com um design arrojado em tons de azul escuro — visando o conforto visual durante o uso noturno (Dark Mode) — a plataforma proporciona uma navegação fluida através de carrosséis interativos de gêneros como "Ação Explosiva", "Ficção Científica" e "Comédias para Relaxar". Em nosso site, o cliente encontra uma experiência visual imersiva, páginas dedicadas a destaques e um sistema direto de suporte na central de ajuda. 

Tudo foi estruturado aplicando o rigor do HTML5 Semântico e do CSS moderno (com Flexbox), pensando para que o usuário assuma o controle do que assiste, sem amarras, assistindo onde quiser e cancelando quando quiser.
